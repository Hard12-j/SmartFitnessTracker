# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.2-SNAPSHOT] - 2026-05-27

### Added
- Multi-stage `Dockerfile` and `.dockerignore` for containerized cloud deployment.
- Walkthrough deployment guide for Render and Aiven MySQL.

### Changed
- Configured environment variable support with default fallbacks in `application.properties` for DB URL/credentials, port, and SMTP settings.
- Bumped project version to `0.0.2-SNAPSHOT` in `pom.xml`.

## [0.0.1-SNAPSHOT] - 2026-05-27

### Added
- Initial project layout for Smart Fitness Tracker.
- Implementation of real-time chat functionality using WebSockets, SockJS, and STOMP messaging.
